# Illusionator: agent rules

Columbia AI Club project testing whether vision models fall for human optical illusions. See README.md.

## Workflow

- Test-first (TDD): write the failing test, run it and see it fail, then implement. Lead with the test on any behavior change.
- Use gstack skills where they fit: `/plan-eng-review` before a feature, `/verify` before committing, `/review` on a diff, `/ship` for PRs. Repo rules here win over skill defaults.
- Review findings need a failing test or a reproduction, or must be labeled unconfirmed.
- Work on a branch and open a PR; don't commit straight to main.

## Authorship

- No AI attribution anywhere in the repo: no `Co-Authored-By` trailers for Claude or any AI, no "Generated with Claude Code" lines in commits, PR descriptions, code comments or docs.
- Commits are authored by the human contributor only.
